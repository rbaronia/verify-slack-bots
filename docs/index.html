verify-slack-bots

Two Cloudflare Workers that connect IBM Verify SaaS to Slack — real-time security alerts and natural-language IAM queries.

Cloudflare Workers IBM Verify SaaS Slack Gemini AI MCP Protocol

🔔 VerifyBot

Real-time audit event alerts + scheduled digest reports

  • Polls IBM Verify Events API every minute
  • Receives push webhooks from IBM Verify
  • AI-classifies events with severity 0–10
  • Posts to #ibm-verify-alerts Slack channel
  • Daily, weekly, monthly, quarterly report digests
  • /report slash command on demand
Full documentation →

🤖 AskIAM

Natural-language IAM queries via /askiam

  • OAuth 2.0 Authorization Code + PKCE per Slack user
  • Tokens cached and auto-refreshed in Cloudflare KV
  • Gemini routes queries to IBM Verify MCP tools
  • Admin ops: users, groups, apps, MFA, directory
  • Self-service: access requests, my MFA, approvals
  • Paginated results with Block Kit buttons
Full documentation →

Why Two Workers?

The IBM Verify MCP server only accepts user Bearer tokens obtained through an OAuth Authorization Code flow — it rejects headless client_credentials tokens.

VerifyBot runs fully headless (cron + webhooks) using client_credentials for the Events API — it cannot call the MCP server.

AskIAM performs a real auth-code + PKCE flow per Slack user, caches tokens in KV, and calls the MCP server on that user's behalf.

Architecture Overview

IBM Verify SaaS  (baronia.verify.ibm.com)
  │
  ├── Events API ──────────────────────────► worker-verifybot
  │     (cron every minute + push webhook)       │
  │                                              ├── Gemini classify (severity 0–10)
  │                                              ├── Slack alerts  #ibm-verify-alerts
  │                                              └── /report digests (1/7/30/90 day)
  │
  └── OAuth / MCP ──────────────────────────► worker-askiam
        (auth-code + PKCE per Slack user)          │
                                                   ├── /askiam slash command
                                                   ├── KV token cache (per Slack user_id)
                                                   └── mcp.baronia.work → IBM Verify APIs

Quick Start

# VerifyBot — events, alerts, reports
cd worker-verifybot
npm install && npx wrangler deploy

# AskIAM — /askiam slash command
cd worker-askiam
npm install
npx wrangler kv namespace create ASKIAM_TOKENS   # first time — paste id into wrangler.toml
npx wrangler deploy
